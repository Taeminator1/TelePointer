# 요구 사항 v1.1

[v1.0/Requirements.md](../v1.0/Requirements.md)에 아래 기능을 더한다. 다시 적지 않은 항목은 v1.0 그대로 유지한다.

## 버전

- **최소 지원 버전 검토**: 지금의 macOS 26에서 더 낮출 수 있는지 검토한다

## 기능

- **한국어 지원**: 메뉴와 설정 창을 한국어로 보여준다. 언어는 시스템 설정을 따른다
- **스크롤**: 단축키로 커서 위치에서 상 · 하 · 좌 · 우로 스크롤한다
- **Hovering**: 단축키로 커서를 옮겨도 마우스를 직접 움직인 것처럼 반응한다
    - 커서 아래 UI의 hover 상태가 곧바로 갱신된다
    - 자동 숨김 Dock이 나타나고, Hot Corners가 동작한다
