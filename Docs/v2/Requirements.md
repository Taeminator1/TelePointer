## 버전

- Tuist: 4.205.0

## 기능

### Pointer 이동

#### 방향 이동

- **방향**: 상 · 하 · 좌 · 우 4방향. 대각선은 두 방향을 연달아 눌러 대신한다
- **입력 방식**: 연타 — 한 번 누르면 한 번 이동한다. 홀드 + 타이머는 쓰지 않는다
    - 키 릴리스를 놓치면 커서가 계속 날아가는 상태 버그가 없고, 1회 = 정확히 정해진 거리다
- **이동 거리**: 미정 — 구현하면서 맞춘다
- **화면 경계 처리**: 미정 — 가장자리에서 멈출지, 인접 모니터로 넘어갈지
- **단축키 조합**: 미정 — [Notes.md](../Notes.md)의 후보표 참고

#### 왼쪽 클릭

- 커서 위치에 왼쪽 클릭을 발생시킨다
- **구현 전 검증이 필요하다.** 합성 클릭은 `CGEvent.post`를 쓰고 접근성 권한을 요구한다.
  v1의 「세 기능 모두 접근성 권한이 필요 없음」 전제가 깨지고,
  App Sandbox + Mac App Store 배포와 함께 갈 수 있는지는 확인되지 않았다.
  스파이크 결과에 따라 범위와 배포 경로를 다시 정한다
- `CGEvent.post`는 반환값이 없어 권한이 없으면 조용히 무시된다 — 실패를 알리는 방법도 함께 정한다

#### 모니터 간 이동 (⌃⌥⌘C)

v1의 「현재 커서가 위치한 디스플레이의 중앙으로 이동」을 대체한다.

- 커서가 현재 모니터의 중앙에 없으면 → 현재 모니터의 중앙으로 이동
- 이미 중앙에 있으면 → 다음 모니터의 중앙으로 이동
- 마지막 모니터에서 누르면 첫 모니터로 돌아온다
- **모니터 순서**: 화면 배치 기준 왼 → 오른쪽 (`NSScreen.frame.origin.x`)
- **모니터가 하나면** 항상 그 화면의 중앙 — v1과 동일하게 동작
- 앱은 순번을 기억하지 않는다. 판단 기준은 매번 커서의 현재 좌표 —
  사용자가 마우스를 직접 움직여도 다음에 갈 곳이 어긋나지 않는다

### 설정 창

- 메뉴바 아이콘의 메뉴에서 진입: Keyboard Shortcuts...
- 별도 윈도우로 제공
- Pointer 관련 단축키를 수정할 수 있어야 한다
- 방향키를 UI로 직관적으로 표현
- 전체를 초기화하는 초기화 버튼 제공
- Text Field에 입력하면 자동 저장
- 완료 누르면 창 이탈
